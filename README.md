# nexigen-python 🐍

A lightweight, async-first **Python 3.12+** library within the **nexigen** framework. Tailored for writing simulator test scenarios, high-level orchestration, telemetry analytics, and seamless AI agent integrations.

## 🚀 Key Architectural Features
* **Async-First Architecture:** Built entirely on top of `asyncio` for non-blocking I/O operations when interacting with other platform nodes.
* **Strictly Typed:** 100% type hinting coverage (`typing`) and data validation powered by `Pydantic` for enterprise-grade codebase reliability.
* **Modern Tooling:** Dependency isolation, building, and publishing managed via ultra-fast modern workflows (`uv` / `Poetry`).

## 🛠️ Core Components
* Asynchronous Logger with native `logging` integration via non-blocking queue handlers.
* Structured telemetry Metrics collector ready for data science workflows.
* Base scripting classes for automated runtime plugin and simulator control.
